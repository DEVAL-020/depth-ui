# 🌌 Depth UI — React & Tailwind CSS Component Library

Build stunning web interfaces faster with 100+ accessible, reusable React and Tailwind CSS components. Create consistent designs with smooth animations, modern effects, and developer-friendly components.

## 🛠️ Tech Stack

- **React 19 & TypeScript**: High-performance, fully typed component primitives.
- **Tailwind CSS v4**: Modern CSS styling with `@tailwindcss/vite`.
- **Three.js & WebGL**: Hardware-accelerated 3D wave meshes, particle terrains, and interactive geometries.
- **Framer Motion**: Smooth spring physics, magnetic cursors, and layout transitions.
- **Lucide React**: Clean, accessible iconography.
- **Vite 8**: Ultra-fast HMR and optimized vendor code splitting.
